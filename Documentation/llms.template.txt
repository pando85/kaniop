# Kaniop

> Kaniop is a Kubernetes operator for declaratively managing Kanidm clusters and identity resources through Kubernetes Custom Resources.

Use this file as the machine-oriented documentation index. Follow only the links needed for the task. For exact fields and validation, prefer the CRDs installed in the target cluster or the generated CRD schema. For repository development tasks, read the repository agent instructions before editing.

Source precedence for operational answers is: installed CRDs via `kubectl explain` > generated CRD schema > generated examples > Helm values/schema > public documentation > internal ADRs and plans > narrative agent guidance.
